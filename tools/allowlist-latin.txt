# 訳文に現れてよいラテン文字の語
#
# 日本語も中国語も、略語・単位・固有名詞・一部の外来語をラテン文字のまま書く。
# 一方、生成の失敗で英語の単語がそのまま残った訳（`office勤務する`、`street gang` など）も
# 同じ見た目になる。両者を機械で見分ける方法が無いため、
# 「使ってよい語」を人手で確かめてここへ並べ、それ以外を tools/validate_data.py が違反として報告する。
#
# 語の切り出しは「連続するラテン文字」単位。`X光` なら `X`、`Big5コード` なら `Big`。
# 数字・記号・漢字・かなは区切りとして扱う。ピンインの欄は対象外。
#
# 語を足すときは、その語がその言語で実際にそう書かれることを確かめてから足す。
# 迷ったら足さずに、訳のほうを直す。
