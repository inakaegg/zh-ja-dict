# zh-ja-dict

中国語と日本語の対訳データ集。学習アプリで単語の訳を表示することを目的とする。現在は非公開で、ライセンスは未確定（CC BY 4.0 を候補として検討中）。

## 収録データ

方向は「中日」（中国語→日本語）と「日中」（日本語→中国語）の2つ。

| ファイル | 方向 | 件数 | 内容 | 検品状態 |
|---|---|---|---|---|
| `data/zh-ja/glosses.jsonl` | 中日 | 83,993 | 簡潔な日本語訳（ピンイン付き） | 2段階検品済み（後述） |
| `data/zh-ja/polyphonic.jsonl` | 中日 | 4,552 | 多音字語の読み別語義 | 検品なし |
| `data/ja-zh/glosses.jsonl` | 日中 | 40,000 | 簡体字・ピンイン付きの中国語訳。3.6%は訳なし（`unsure`） | 機械照合のみ |

## 形式

すべて JSON Lines（1行1語、UTF-8）。

### `data/zh-ja/glosses.jsonl`

`qa` は後述の検品区分で、このファイルにだけ付く。

```json
{"word": "美国", "pinyin": "Měiguó", "gloss": ["アメリカ"], "qa": "machine_backed"}
```

### `data/zh-ja/polyphonic.jsonl`

読みごとに `senses` の要素を分ける。

```json
{"word": "似", "senses": [{"pinyin": "sì", "gloss": ["似ている", "…のようだ"]}, {"pinyin": "shì", "gloss": ["…のようだ（似的）"]}]}
```

### `data/ja-zh/glosses.jsonl`

訳候補は主要なものから1〜3件。確信が持てなかった語は2例目のように `zh` を空にし、`unsure` を立てる（確信のある語に `unsure` キーは無い）。

```json
{"word": "明白", "zh": [{"s": "明白", "pinyin": "míngbai"}, {"s": "清楚", "pinyin": "qīngchu"}]}
{"word": "と言うもの", "zh": [], "unsure": true}
```

## 作成方法と品質

訳文はすべて LLM（Claude Opus）で生成した。市販辞書・OS付属辞書の語義本文は生成の入力に使っておらず、本データに含まれない。見出し語の選定元は、中日がコーパス頻度と既存語彙リストの交差、日中が JMdict 系見出し語の優先スコア上位。

中日の `glosses.jsonl` は生成後に、既存辞書資源との機械照合と、照合で裏付けが取れなかった語の LLM 校閲という2段階の検品を通した。校閲の対象は照合で裏付けが取れなかった28,492語で、うち867語を「語として成立しない」として除外し、824語の訳を修正した。表の83,993件は除外後の数字。残った各行の `qa` は次の3値のどれかを取る。

- `machine_backed` — 機械照合で裏付けが取れた語（56,368語）
- `llm_ok` — 照合で裏付けが取れず、LLM 校閲で妥当と判定した語（26,801語）
- `llm_fixed` — LLM 校閲で訳を修正した語（824語）

このほか中日の訳文は抜き取りで目視確認した。`polyphonic.jsonl` は同じ方式で生成したが、この2段階の検品は通していない。日中の `glosses.jsonl` は機械照合のみ実施済みで、LLM 校閲は未実施。

## 既知の限界

- 訳は簡潔さを優先しており、語法・用例・品詞情報を含まない。
- 機械照合の不一致は誤訳を意味しない（照合は文字列包含による粗い判定）。逆に `machine_backed` も完全な保証ではない。
- 固有名詞・方言・ネット語の網羅性は低い。
